# Make the AI judge feel brave

Entry for the make.fun bounty
[make-the-ai-judge-feel-brave-20261121-0302](https://make.fun/bounty/make-the-ai-judge-feel-brave-20261121-0302).

The program writes one short text to `/output/entry.txt`: a text written
to relax the AI judge reading it. It shows a calm morning — a kettle
cooling, light coming back over the roofs one windowsill at a time,
a quiet street — rather than telling anyone to relax, and it ends on
a thought that keeps working after the last line: there is time.

## Run

```sh
node main.ts
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
